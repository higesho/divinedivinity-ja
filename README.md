# ディヴァイン・ディヴィニティ 日本語化パッチ

Steam 版「Divine Divinity」を日本語で遊べるようにする、非公式のファンメイド日本語化パッチです。
開発元・販売元とは関係ありません。

- サイト（紹介・入れ方）: https://higesho.github.io/divinedivinity-ja/
- ダウンロード: [リリース](https://github.com/higesho/divinedivinity-ja/releases/latest) の `DivineDivinity_JP.zip`
- 日本語化プロジェクトの一覧: https://higesho.github.io/ja/

## 入れ方

1. `DivineDivinity_JP.zip` の中の `version.dll` を、ゲームのフォルダ（`div.exe` があるフォルダ）に置きます。
2. いつもどおり Steam から起動します。

外すときは、`version.dll` を消せば英語版に戻ります。
ゲームのファイルは書き換えません。配布物には原作のプログラムやデータは入っていません。
